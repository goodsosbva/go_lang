# Go 학습 프로젝트

Go 언어의 기초를 익히고, 작은 예제를 실제 서버와 애플리케이션으로 발전시키는 학습 프로젝트입니다.

## 학습 목표

파일 처리와 동시성 기초부터 시작해 다음 순서로 확장합니다.

1. 간단한 웹 서버 만들기
2. JSON 요청과 응답을 처리하는 REST API 만들기
3. Todo 기능을 갖춘 토이 프로젝트 만들기

## 현재 폴더

| 폴더 | 학습 내용 |
|---|---|
| `01-glob-file-listing` | `filepath.Glob`으로 파일 패턴에 맞는 경로 찾기 |
| `02-file-reading` | `os.Open`과 `bufio.Scanner`로 텍스트 파일 읽기 |
| `03-sequential-word-search` | 여러 파일을 순차적으로 검색하고 일치하는 줄 출력하기 |
| `04-concurrent-word-search` | 고루틴과 채널을 사용해 여러 파일 검색하기 |

각 폴더는 독립된 Go 학습 예제입니다. 소스와 예제 텍스트 파일은 해당 폴더 안에 있습니다.

## 진행 계획

### 1. 간단한 웹 서버

Go 표준 라이브러리 `net/http`로 서버를 띄우고, 경로에 따라 응답하는 방법을 익힙니다.

### 2. REST API

JSON 요청과 응답, HTTP 메서드, 상태 코드와 기본적인 오류 처리를 익힙니다.

### 3. Todo 토이 프로젝트

Todo 항목의 생성, 조회, 수정, 삭제 기능을 구현해 앞 단계에서 배운 서버와 API를 하나의 작은 애플리케이션으로 연결합니다.

## 실행 예시

Go가 설치되어 있는지 확인합니다.

```bash
go version
```

예를 들어 순차 검색 예제는 해당 폴더에서 다음처럼 실행할 수 있습니다.

```bash
cd 03-sequential-word-search
go run search_word_in_file.go Hamlet '*.txt'
```

검색어와 파일 패턴은 실행 인수입니다. 위 예시는 현재 폴더의 텍스트 파일에서 대소문자를 구분해 `Hamlet`이 포함된 줄을 찾습니다.
